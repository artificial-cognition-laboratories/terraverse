**Terraverse 0.1.15: time, and a snappier menu**

- `/time`: see the time of day, set it, or skip the universe forward.
- The library opens at once: mods, the registry and servers show what you saw last time straight away, then update as the live list comes in. The mod page's sidebar stays put as you scroll.
- The menu music plays as soon as the game starts, without a click first.
- The account panel and the new-world screen are the same glass as the rest of the menu, and the UI has small rounded corners.
- The game starts on Linux systems without libpng in the usual place, such as NixOS: it now comes with the game.
- Closing the game while a planet was still being built in the menu could crash it. It doesn't any more.
- Worlds made before this release open as normal: the game's id changed from `terrafirma` to `terraverse`, and each world is updated the first time it's opened.
