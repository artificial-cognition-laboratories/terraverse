# start/

The server's starting state: its worlds as they should be on day one. Written by
`terra snapshot`, returned to by every reset, and opened by anyone who installs the
server from the registry.

Like `save/`, what's inside is the server's business. Unlike `save/`, it's source: commit it,
and it travels with the server when you publish.

A server without one starts from its world code alone.

Not designed yet.
