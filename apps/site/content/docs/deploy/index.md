# Deploy

Your server folder, kept online by us.

> Managed hosting isn't available yet. These pages are how it will work.

```bash
terra deploy
```

The same folder you run with `terra serve`, running on our machines instead: always on, reachable
by name, backed up as it plays, and costing next to nothing while nobody's there. Nothing about
the server changes. The same rules, the same mods, the same save.

## Free to run anywhere

Everything in Terraverse is free and open: the game, the mod API, the registry, and hosting
your own server. `terra serve` on your PC, a spare machine or any VPS runs exactly what we run.

Managed hosting is for when you'd rather not: a universe that's up when you're asleep, reachable
without opening ports, backed up without you thinking about it. You pay for the looking-after,
never for access.

And you can always leave. Your save downloads as an ordinary server folder, which runs anywhere
`terra serve` does.

## What you get

| | Your machine | Deployed |
|---|---|---|
| Runs | While it's on | Always |
| Reachable | Friends, through the relay | Anyone allowed, by name |
| Nobody online | Running, or off | Asleep: time still passes, almost free |
| Backups | Yours to take | Continuous, with history to rewind |
| Updates | Restart it yourself | `terra deploy`, no downtime |
| Listed publicly | No | If you choose |

## A universe that keeps time while it sleeps

When the last player leaves, a deployed server sleeps. Nothing near anyone needs simulating
live, so the whole universe runs scheduled: crops still ripen, kilns still finish firing, carts
on routes still arrive, all at the times they would have. The first player to join wakes it, and
finds a world that carried on without them.

That's what makes a long-lived universe affordable. A server that's empty most of the day costs
for the hours it's played, not the hours it exists.
