# `terra version`

Print the installed version of Terraverse, and the mod API it implements.

```bash
terra version
terra --version
```

```
terra 0.2.0 · mod api 0.2
```

The API version is the one this terra writes into a project's `.terra/types/`, and records in what you publish.
