# `terra deploy`

Run the server you're standing in on managed hosting, and look after it there.

```bash
terra deploy                      # the first time: the whole universe. after: its rules
terra deploy --rollback           # the previous rules back
terra deploy --rewind "2 hours ago"
terra deploy --fork verdant-test
terra deploy --pull               # the save, downloaded into save/
terra deploy --down               # stop it, keep everything
```
